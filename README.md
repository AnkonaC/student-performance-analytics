# Student Performance Analytics System

## Project Overview

The Student Performance Analytics System is a Python-based data analysis project that analyzes student academic performance using Python, NumPy, and Pandas.

The system reads student information from a CSV file and calculates marks, averages, grades, pass/fail status, subject-wise performance, and top-performing students.

## Objective

The main objective of this project is to analyze student performance and generate meaningful results from a student dataset.

The system helps answer questions such as:

- What is the average performance of the class?
- Which student has the highest average?
- Which student has the lowest average?
- How many students passed or failed?
- Which subject has the highest average?
- Who are the top-performing students?

## Technologies Used

- Python
- NumPy
- Pandas
- VS Code
- GitHub

## Dataset

The project uses a CSV file named `students.csv`.

The dataset contains 20 student records with the following fields:

- Student ID
- Name
- Department
- Python marks
- Mathematics marks
- Computer Networks marks
- Attendance
